# Database Operations

This area groups database auditability and release-readiness practices that were separate in the source repository.

- [Audit logging](audit-logging/README.md): event coverage, central collection, one-year retention design, lifecycle transition, access boundary, and validation.
- [Managed database upgrade / RCA](../rds-upgrade-rca/README.md): upgrade strategy, parameter-group review, application coordination, and follow-up actions.
- [Migration considerations](../migration/README.md): network and application dependency changes that can affect database reachability.

The source material included database migration and log-retention work. Public examples omit real instance names, database endpoints, account IDs, exported logs, and internal incident links.
